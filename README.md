# medicalstoarmanagementsystem
Medical Store Management System

Project Overview

The Medical Store Management System is a desktop application developed to manage medical store operations efficiently.

Technologies Used

- C#
- Windows Forms
- SQL Server
- Visual Studio

Features

- Login System
- Add and Manage Medicines
- Medicine List and Search
- Purchase Management
- Sales Management
- Sales Invoice
- Low Stock Report
- Dashboard

Project Type

BCA Final Year Project
